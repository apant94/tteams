# Team

**Team** — небольшая приватная платформа для переписки мастера с клиентами.

Клиент видит только свой диалог с мастером. Администратор видит список клиентов
и может открыть отдельную переписку с каждым из них.

## Возможности MVP

### Для клиента

- вход по персональному паролю;
- один личный чат с мастером;
- отправка сообщений;
- просмотр истории переписки;
- автоматическое получение новых сообщений.

### Для администратора

- вход в панель администратора;
- список клиентов;
- отдельный чат с каждым клиентом;
- отправка сообщений;
- просмотр истории переписки.

## Технологии

- PHP 8.2+;
- HTML;
- CSS;
- JavaScript;
- SQLite.

Сторонние зависимости, Composer и Node.js для запуска не нужны.

Новые сообщения загружаются с помощью polling: браузер обращается к серверу
каждые три секунды. Для текущего количества пользователей WebSocket не требуется.

## Как работает платформа

1. Пользователь вводит выданный ему персональный пароль.
2. Сервер проверяет хэш пароля и создаёт PHP-сессию.
3. Клиент попадает в единственный доступный ему чат.
4. Администратор видит список клиентов и выбирает нужный диалог.
5. История хранится в SQLite, а новые сообщения появляются автоматически.

## Безопасность

- пароли хранятся только в виде хэшей;
- запросы к SQLite выполняются через PDO и prepared statements;
- после входа обновляется идентификатор сессии;
- формы защищены CSRF-токеном;
- сервер проверяет доступ пользователя к запрошенному диалогу;
- пользовательский текст выводится без выполнения HTML и JavaScript.

## Локальный запуск

Потребуется PHP 8.2 или новее с поддержкой SQLite.

### 1. Скачать проект

```bash
git clone https://github.com/apant94/tteams.git
cd tteams
```

Если репозиторий приватный, владелец должен предварительно предоставить доступ.

### 2. Проверить PHP

```bash
php -v
```

### 3. Подготовить базу

```bash
php bin/database-migrate.php
php bin/database-seed-demo.php
```

Команды создадут `storage/app.sqlite`, двух тестовых пользователей и один диалог.

### 4. Запустить сервер

```bash
php -S localhost:8000 -t public
```

После запуска открыть `http://localhost:8000`.

### 5. Проверить переписку

В обычном окне браузера войти как администратор:

```text
admin-demo
```

В приватном окне войти как клиент:

```text
client-demo
```

Разные окна нужны для двух независимых сессий. Новые сообщения появляются
автоматически примерно через три секунды.

Остановить сервер можно сочетанием `Ctrl+C`. Если порт `8000` занят:

```bash
php -S localhost:8080 -t public
```
